CAPTURE ZEUS - whole-city panorama - Zeus: Master of Olympus (Zeus / Poseidon)
==============================================================================
(Version française : LISEZMOI.txt)

What it is for
--------------
The game only shows part of the city at a time. This program scrolls the view
by itself, takes a screenshot at every step, then stitches all the screenshots
into one big picture: a panorama of the whole city.

Only "Capture Zeus.exe" is needed: nothing to install. It runs on Windows 7
to 11 (.NET Framework 4, already present on Windows 10 and 11), at any game
resolution.

On first launch, Windows may show "Windows protected your PC" (downloaded,
unsigned program): click "More info", then "Run anyway".

How to use it
-------------
1. Start Zeus and open the city to capture.
2. Put the view roughly in the middle of the city.
3. Pause the game (P key).
4. Run "Capture Zeus.exe" and choose:
   - "Full-resolution capture": panorama at the game's real size;
   - or "Half-size capture": panorama 2 times smaller and lighter.
5. The banner turns red: DO NOT TOUCH THE MOUSE OR THE KEYBOARD ANY MORE.
   The music starts, then 3 seconds later the program switches to the game
   by itself, mutes it and scrolls the view.
6. When the sweep is over, the game sound comes back and the program window
   comes to the front again (orange banner): you can use your computer while
   the panorama is being assembled.
7. When the music stops, the panorama is ready (green banner). The
   "View the panorama" and "Open the folder" buttons appear.

The "Language" list at the top right switches the program between French and
English; the choice is kept for next time. The "No music" box makes the
capture silent. The working music is a short melody generated by the program;
to use your own, put a "music.wav" file next to "Capture Zeus.exe".

Where the pictures are
----------------------
Each capture creates a "capture_YYYYMMDD_HHMMSS" folder next to the program:
- panorama.png (or panorama_x0.5.png for the half-size capture): the result;
- frame_0001.png, frame_0002.png...: the individual screenshots;
- positions.csv: the place of each screenshot in the panorama.
The screenshots can be deleted once you have checked the panorama.
Put the program in a folder where you can write (not in Program Files),
since its capture folders are created next to it.

Good to know
------------
- Moving the mouse during the capture stops it (on purpose: it is the way to
  interrupt it). Just start again.
- An accidental Alt+Tab breaks nothing: the capture pauses and resumes
  3 seconds after you go back to the game (go back with Alt+Tab, without
  clicking on the map or scrolling it).
- If you close the window during a capture, the program asks for confirmation
  and turns the game sound back on before quitting.
- If the view already touches an edge of the map at the start, the program
  copes with it; starting from the middle of the city is still the safest.
- The sea is animated even when the game is paused: a few screenshots over a
  sea with no landmarks may be placed by estimation (a message says so at the
  end).
- If the message "The capture is black" appears, Windows cannot capture the
  game: run it in windowed mode (cnc-ddraw or DxWnd) and try again.
- Some antivirus programs may distrust this program because it simulates
  arrow key presses and takes screenshots: that is exactly its job. It never
  connects to the Internet and only writes into its "capture_..." folders.
  Its source code is supplied in the "source" folder (.cs files).

Advanced use (command line)
---------------------------
"Capture Zeus.exe" test
    Checks the screen capture and the scrolling without making a panorama
    (check images test_full.png and test_vue.png).
"Capture Zeus.exe" assembler FOLDER [SCALE]
    Rebuilds the panorama of a capture_... folder already saved
    (SCALE: 1 by default, 0.5 for half size).
Options: --delai SECONDS (delay before starting, 3 by default),
         --silencieux (no music),
         --lent (careful scrolling, if screenshots end up misaligned).
Command-line messages follow the language chosen in the window.
